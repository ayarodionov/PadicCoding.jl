Binary p-adic Coder

An animated run of the revised p-adic arithmetic coder with P = 2 on a small grid G(28): 256 cells, each a leaf of the binary coding tree. The message narrows an interval [l, r); when the tree paths to l and r−1 share a prefix, that prefix is output and the interval is rescaled (PR). When the interval sits around ½, it is stretched and one bit is deferred (AR). The trace matches padic_encode2 bit for bit.

Reading the picture

A grid index x written in 8 binary digits, most significant first, is the path from the root to leaf x (0 = left, 1 = right). Read from the leaf upward, the same digits form the 2-adic integer x^; the IP transform ^ only reverses them.

The 2-adic distance |l^ − (r−1)^|₂ = 2^−n where n is the length of the shared path. Once it drops below 1, every point of the interval lies in one subtree and its n path bits are final.

With P = 2 the AR stable point is always ½, so the coder only counts how many times it stretched around it.
